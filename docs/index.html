Step 1: Create Scenario and Configure Z-stack Acquisition

Action: Load or create a Scenario with the specified configuration as shown above

Explanation: This step will automatically create a Scenario that will acquire z-stack of beads.

Tip: Make sure you use a slide that with tetraspek beads (100-200nm) that are well adhered to the coverslip. You can use poly-L-lysine to help with adhesion if needed.

Step 2: Optimize Laser Intensity and Set Z-stack Start Position

Action: Test what the optimal laser intensity is for both 561 and 488 laser lines and make sure you adapt the values in the scenario.

Explanation: This step aims to optimize SNR and z-stack imaging conditions.

Tip: Focus in the middle of the z-stack and adjust the laser power to get a good signal without saturating the beads. You can also adjust the exposure time if needed, but try to keep laser power as low as possible to minimize photobleaching.

Step 3: Move Focal Plane to Set Z-stack Start Position and start acquisition

Action: Move the focal plane closer to the coverslip. This way you set where the start of the z-stack is and press start.

Tip: If you want to do a 1 Î¼m z-stack, adjust the focal plane about 500nm below the middle of the beads.

Part 2 - ImageJ + Calibration

Step 1: Perform Initial Setup

Action: Open tif images from part 1 in ImageJ (FIJI) as a stack and then save R-camera and T-camera to separate tif files.

Explanation: Here you are preparing the acquired data for the calibration step. The R and T camera images will be used to compute the calibration transformation.

Tip: In ImageJ import the files as a stack (File > Import > Image Sequence) and make sure to select the correct folder and file pattern. Once the stack is open, you can use the ‘Split Channels’ function (Image > Color > Split Channels) to separate the R and T camera images. Then, save each channel as a separate tif file (File > Save As > Tiff).

Step 2: Load Images and Configure Detection Settings in NeoLiveImaging

Action: In NeoLiveImaging click ‘System’ > ‘Detection Settings’ > ‘Load files’. Then click ‘show second camera’ and ‘deselect use z-stack infos’. Load R-camera and T-camera images.

Explanation: Here you are loading the saves z-stacks necessary for PSF calibration. By deselecting ‘use z-stack infos’ you are making sure that the software does not use the z-stack metadata to set the z-step size, which is important for accurate calibration.

Step 3: Set Z-step Size and Selection of Beads for Calibration

Action: Type in the correct z-step size (e.g. 100nm) and click ‘Next’. Then software will automatically select beads of high quality to perform calibration.

Explanation: Here the software will automatically select beads that are bright, well-defined, and not overlapping or too close to the edges of the field of view.

Tip: Focus on the highlighted region and watch the short clip for temporal context.

Step 4: Adjust Z-range and Remove Outliers

Action: The calibration is now done and we will adjust a few things. First, adjust the zmin and zmax values to set the range for the calibration (recommended values: ‘zmin’ = -600 and ‘zmax’ = 600). Second, by clicking ‘show curve info’ you can deselect the beads that are far from the general trend (outliers).

Explanation: Here you are adjusting the z-range for the PSF calibration and removing outliers. The z-range should be set to include all the beads that were selected for calibration. Removing outliers can help improve the accuracy of the calibration by excluding beads that do not fit the general trend.

Tip: Only remove the outliers that are very far from the general trend. You can toggle the mean for each algorithm to evaluate.

Step 5: Repeat for all localization algorithms

Action: Repeat for all localization algorithms: Phasor, GaussianLSQ, GaussianMLE, C-spline

Step 6: Save Calibration and Export Results to a folder

Action: After clicking ‘Next’ in the new panel select ‘use polynomial calibration’, select directory to save PSF calibrations, and click finish.

Explanation: Here you are saving all calibrations to a folder to use with NeoAnalysis for lo3D localization.
